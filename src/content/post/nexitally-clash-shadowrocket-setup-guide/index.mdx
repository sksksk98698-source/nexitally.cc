## 三、iOS 平台：Shadowrocket（小火箭）配置实操

Shadowrocket 是 iOS 平台上性能优异、分流规则极其成熟的代理管理工具。

### 1. 订阅导入流程
1. 打开 Shadowrocket，点击主界面右上角的 **「+」** 图标。
2. 在「类型」下拉菜单中选择 **「Subscribe」**。
3. 在「URL」栏中长按粘贴从 Nexitally 后台复制的专属订阅链接。
4. 在「备注」栏填入 `Nexitally 官方专线`，点击右上角「完成」。
5. 软件将自动向 Nexitally 订阅服务器发送请求并拉取完整节点列表。若未自动拉取，在首页将该订阅行向左轻扫并点击「更新」即可。

### 2. 全局路由与 DNS 推荐设置
- **全局路由模式**：务必保持默认的 **「配置（Config）」** 状态。切勿随意切换为「代理（Proxy）」，以免国内应用全部绕行海外专线导致延迟增加及国内应用 IP 异常。
- **开启自动更新订阅**：进入「设置」→「订阅」→ 开启「打开时更新」与「自动后台更新」，确保节点 IP 发生运维调度时自动同步。
- **节点筛选**：根据业务需求选取节点。需要处理文字工作及大模型请优先选用带 `[AI优选]` 的新加坡或日本节点；需要观看流媒体请选用带 `[原生流媒体]` 的香港或美国节点。

## 四、桌面端：Clash Verge Rev / Clash Meta 进阶配置

Clash Verge Rev（基于开源 Mihomo / Clash Meta 内核）是当前 Windows 与 macOS 平台性能最强、支持协议最全的主流客户端。

### 1. 导入订阅与配置更新
1. 下载并安装最新稳定版 Clash Verge Rev。
2. 启动后进入左侧 **「订阅 (Profiles)」** 面板。
3. 在顶部输入框粘贴 Nexitally 专属订阅地址，点击「下载 (Download)」。
4. 下载成功后，右键点击该配置卡片，选择 **「编辑信息」**，将「更新间隔」设置为 `1440` 分钟（24小时自动更新），或在系统托盘右键一键手动更新。
5. 左键单击该配置，使其高亮变为激活状态。

### 2. TUN 虚拟网卡模式（解决命令行与 UWP 代理痛点）
传统「系统代理（System Proxy）」仅能拦截设置了系统环境变量或调用系统 HTTP 代理接口的浏览器流量，对于 Windows 终端（PowerShell / CMD）、Git、Docker、游戏客户端或跨国远程桌面无效。

**启用 TUN 模式步骤：**
1. 进入 Clash Verge Rev 的 **「设置 (Settings)」** 页面。
2. 找到 **「TUN 模式 (TUN Mode)」** 并开启开关。
3. Windows 平台首次开启会自动安装高性能 `Wintun` 虚拟驱动；macOS 则会请求系统网络拓展权限，按提示输入系统密码授权。
4. 开启 TUN 模式后，系统所有底层三层 IP 数据包均会被虚拟网卡拦截并依据规则智能分流，无需再为各个软件单独配置代理端口。

### 3. DNS 防污染与 Fake-IP 最佳实践配置
在 Clash 内核中，推荐采用 Meta 内核的混合 DNS 方案以彻底杜绝 DNS 污染与 DNS 泄漏：

```yaml
# Nexitally 推荐 DNS 策略片段 (Clash Verge 扩展配置)
dns:
  enable: true
  listen: 0.0.0.0:1053
  ipv6: false
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  fake-ip-filter:
    - '*.lan'
    - 'localhost.ptlogin2.qq.com'
    - '+.msftconnecttest.com'
    - '+.msftncsi.com'
  nameserver:
    - 223.5.5.5
    - 119.29.29.29
  fallback:
    - https://1.1.1.1/dns-query
    - https://8.8.8.8/dns-query
```

## 五、连接排错诊断决策树（常见问题与速查方案）

遇到连接异常时，请对照下表进行针对性定位排查：

| 异常现象 | 核心排查方向 | 推荐解决方案 |
| :--- | :--- | :--- |
| **订阅更新提示 Network Error / 400** | 本地网络阻断或订阅链接不完整 | 检查复制链接是否包含特殊字符；尝试在浏览器直接访问该链接看是否返回编码字符；临时开启手机热点尝试更新。 |
| **全节点测速显示 Timeout 或 0ms** | 系统本地时间误差或本地代理端口冲突 | 1. 重新同步 Windows/Mac Internet 时间；<br/>2. 检查是否有其他代理软件残留（如旧版 Clash、Fiddler）；<br/>3. 重启客户端内核。 |
| **网页可以打开，但微信/QQ 频繁断线** | 分流规则将即时通讯流量错误分流 | 检查是否误开启了「全局模式 (Global)」；将模式切换回「规则模式 (Rule)」，并将国内软件添加至 Direct 直连规则。 |
| **访问 OpenAI / Claude 提示 1020 / 403** | 节点 IP 处于高频调用风控区间 | 切换至 Nexitally 标有 `[AI优选]` 或美西/新加坡专属节点；详见 [AI 生产力稳定连接指南](/blog/chatgpt-claude-remote-office-network-best-practices)。 |
| **开启 TUN 模式后电脑无法解析局域网打印机** | Fake-IP 过滤名单未包含局域网网段 | 在 DNS 配置中将 `*.local`, `192.18.*`, `10.*` 加入 `fake-ip-filter` 白名单中。 |
