## 二、什么是 IEPL 与 IPLC？物理专线的核心本质

要彻底终结晚高峰卡顿，唯一的工程学解法就是采用**运营商二层物理专线**。

### 1. IPLC（International Private Leased Circuit，国际私有租用线路）
IPLC 是电信运营商提供的点对点数字专用线路。它相当于在两个国家或地区的数据中心之间铺设了一条完全私有的内网铜缆或光纤通道。
- **物理隔离**：不与任何公众互联网流量混跑，内部传输的数据包无需经过公网出入口检查。
- **确定性时延**：物理路径固定，数据传输时间仅受光在二氧化硅光纤介质中的折射传播速度限制（约 200km 每毫秒）。

### 2. IEPL（International Ethernet Private Line，国际以太网专线）
IEPL 是基于现代以太网技术构建的增强型专线服务，采用标准以太网接口（如 10GE/100GE）直接封装传输：
- **更强的协议透明性**：完美支持二层以太网数据帧透传，具备更高的协议兼容性与极低的帧封装开销。
- **动态微秒级倒换**：具备双环自愈或多路径保护（APS）机制，当某一条海缆发生海底地震割接时，可以在 50 毫秒内实现无感物理切换。

## 三、为什么选择轻量化 VLESS 协议？

除了底层的物理光纤专线，传输层与应用层的协议选择同样至关重要。Nexitally 全线推荐并默认使用 **VLESS 协议（结合 TLS 1.3 与 XTLS 技术）**，这是代理协议发展史上的重要里程碑。

### 1. 传统代理协议的历史局限
- **Shadowsocks (AEAD)**：虽然轻量，但在长连接抗并发小包处理上效率有限，且流量特征在特定环境下容易被识别。
- **VMess**：早年为公网混淆设计，引入了严格的时间戳认证与繁琐的客户端本地二次对称加密。这一设计在普通 CPU 上造成了大量内存拷贝与运算消耗，在高并发吞吐时容易成为瓶颈。
- **Trojan**：虽然采用了标准 TLS 伪装，但早期实现依然存在双重 TLS 握手开销。

### 2. VLESS 的技术突破与核心优势
VLESS（VMess Less）由社区顶级架构师设计，其核心哲学是**极致精简，不重复造轮子**：

1. **移除内层冗余加密，拥抱标准 TLS 1.3**：
   既然外层连接已经由标准的 TLS 1.3 进行了高强度端到端加密，内部再进行二次加密纯属浪费系统算力。VLESS 移除了冗余加密，将客户端与服务端的 CPU 占用降低了近 40%。
2. **XTLS-Vision 流控与零内存拷贝（0-Copy）**：
   在结合 XTLS 之后，对于本就已经是 TLS 加密的外层数据（如 HTTPS 网页、YouTube 4K 流、TikTok 视频推流），代理内核可直接跳过用户态与内核态的重复内存复制，直接将 TCP Payload 注入网卡发送，吞吐量提升超过 100%。
3. **0-RTT 极速握手**：
   结合 TLS 1.3 协议的 Early Data 特性，客户端可在初次连接建立的同时发送首个请求数据包，省去了一个完整的往返确认时间（RTT），极大提升了网页首屏与 API 调用的瞬时加载速度。
