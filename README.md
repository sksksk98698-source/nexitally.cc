## 📖 项目简介

本项目为 **Nexitally（奶昔）** 官方授权品牌官网落地页与技术知识库门户。基于 **Astro 6 + Tailwind CSS v4** 深度定制开发，采用 100% 现代静态站点生成（SSG）架构，具备极致的首屏加载性能、企业级设计美学、全站暗黑模式自适应以及严苛的搜索引擎与生成式 AI（GEO）收录标准。

网站面向高标准跨境出海团队、海外 AI 工具从业者、4K 影音发烧友及远程办公团队，提供全透明的专线参数、卡片式套餐展示、多端接入指南与排障知识库。

## 🛠️ 技术栈

- **框架核心**：[Astro 6.4.2](https://astro.build) (Content Layer API, Static SSG)
- **样式引擎**：[Tailwind CSS v4.1](https://tailwindcss.com) + `@tailwindcss/vite`
- **内容体系**：[MDX](https://mdxjs.com) (`@astrojs/mdx`) + 结构化 Content Collections
- **动效组件**：[AOS](https://michalsnik.github.io/aos/) (Scroll Animation) + [Motion](https://motion.dev/)
- **图标系统**：[Lucide Icons](https://lucide.dev/) (`@lucide/astro`)
- **构建工具**：[Vite 7.3](https://vite.dev/) + [pnpm](https://pnpm.io/)
- **代码诊断**：TypeScript + `astro check`

## 🚀 快速开始

### 1. 克隆项目与安装依赖

```bash
git clone https://github.com/sksksk98698-source/nexitally.cc.git
cd nexitally.cc

# 推荐使用 pnpm
pnpm install
```

### 2. 启动本地开发服务

```bash
pnpm dev
```

本地服务将启动于 `http://localhost:5200`，支持热更新（HMR）。

### 3. 类型诊断与构建检查

```bash
# 静态类型检查
pnpm astro check

# 全站生产编译
pnpm build
```

编译生成文件位于 `dist/` 目录，全站 18 个路由及 XML 站点地图将完全静态生成。

### 4. 预览生产产物

```bash
pnpm preview
```

## 🌐 生产部署建议

本项目为纯静态产物，可部署于任何现代静态托管网络：

### Cloudflare Pages（推荐）
- **构建命令**：`pnpm build`
- **构建输出目录**：`dist`
- **环境变量**：`PUBLIC_SITE_URL` = `https://nexitally.cc`
- **建议配置**：在 Cloudflare 中添加页面重定向规则，将 `https://www.nexitally.cc/*` 301 重定向至 `https://nexitally.cc/$1`。

### Vercel / Netlify
- 平台自动识别 Astro 项目，配置 Framework Preset 为 `Astro`，输出目录填写 `dist` 即可开箱即用。
